# Adriano Ventura Elu - Mathematics & Leadership Portfolio

A personal portfolio website showcasing my work in mathematics, leadership, and technology.

## Description

This is my professional portfolio built with HTML, Tailwind CSS, and vanilla JavaScript. It features:
- Responsive design
- Contact form with EmailJS integration
- Modern UI with animations
- Font Awesome icons

## Live Site

Visit the live site at: [https://adrianoblog038.github.io/Adriano_Elu/]

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (ES6+)
- EmailJS for contact form
- Font Awesome icons
- Google Fonts (Inter & JetBrains Mono)

## Local Development

To run locally:
1. Clone this repository
2. Open `index.html` in your web browser

No build process required - it's a static site using CDN links.
